# Monovision Studio

A responsive website for Monovision Studio, developed based on a provided design mockup.

## About the Project

Monovision Studio is a portfolio-style website showcasing the studio's creative work, inspiration, and clients.

The main goal of this project is to accurately implement the provided design using HTML and SCSS while following semantic markup principles, the BEM methodology, and responsive web design practices.

## Technologies

- **HTML5** — semantic page structure.
- **SCSS** — styling and CSS code organization.
- **BEM** — CSS class naming methodology.
- **Flexbox** — flexible layouts and element alignment.
- **CSS Grid** — grid-based layouts and content positioning.
- **Media Queries** — responsive layouts for different screen sizes.

## Features

- Semantic HTML structure.
- BEM naming convention.
- SCSS nesting for better style organization.
- Combination of Flexbox and CSS Grid.
- Responsive design based on the breakpoints specified in the design mockup.
- Reusable styles for common elements.

## Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
